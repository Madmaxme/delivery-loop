# Agents

This repository is the delivery-loop engine. The master methodology is [conduct/methodology/SKILL.md](conduct/methodology/SKILL.md). The Cursor rule is [.cursor/rules/delivery-loop.mdc](.cursor/rules/delivery-loop.mdc). Code conduct is [conduct/conduct/SKILL.md](conduct/conduct/SKILL.md). Follow that file. Do not paste it into a client repo.

An edit of this package does not merge to `main`. Open a pull request. Branch `engine-heal/<ticket>` and label `engine-heal` when the edit is a heal of this package. That pull request already contains the next patch after the highest `v*` tag. The `pull_request` `quality` check gates it. The engine-heal workflow does not push a commit. It squash-merges only when the pull request has that branch and the `engine-heal` label, every changed file is on the auto-merge allowlist: `src/connectors` source, or a version-only package.json and package-lock.json. `src/engine`, `src/adapters`, `src/schema`, `src/bots`, and any other path need a normal review, and the green run is a GitHub Actions `pull_request` run of `.github/workflows/quality.yml` on that exact head whose file matches `main`. Anything else, including an unknown proof, gets a comment and a normal review. The workflow does not merge or tag it. A pull request without the bump gets a comment and stops. Clients install a git tag, not `main`.

Commit subjects are one plain sentence. The body explains the change. See [CONTRIBUTING.md](CONTRIBUTING.md).
